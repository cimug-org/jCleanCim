# jCleanCim logo

The jCleanCim logo is the CIM Users Group disc with two additions for what the tool does: the network's right-hand node is a sparkle, with a small glint outside the disc, for **validation** (a clean model), and a page badge for **document generation** (IEC publication documents).

| File | Use |
|---|---|
| `jcleancim-logo.svg`, `jcleancim-logo-1200.png` | Logo and wordmark, for light backgrounds |
| `jcleancim-logo-dark.svg`, `jcleancim-logo-dark-1200.png` | Logo and wordmark, for dark backgrounds (the website header) |
| `jcleancim-mark.svg`, `jcleancim-mark-<size>.png` | The mark alone, for light backgrounds and icons (16 to 512 px) |
| `jcleancim-mark-dark.svg`, `jcleancim-mark-dark-512.png` | The mark alone, for dark backgrounds |
| `favicon.ico` | Browser icon (16, 32 and 48 px); a copy is at the repository root for the website |
| `jcleancim-social-1280x640.png` | GitHub social preview (Settings › Social preview) |

The wordmark is set in [Montserrat](https://github.com/JulietaUla/Montserrat) (Regular for "jClean", SemiBold for "Cim") and converted to outlines, so the SVGs need no fonts. Montserrat is licensed under the SIL Open Font License; see `Montserrat-OFL.txt`.

Colours are from the CIM Model Management brand palette: the disc keeps the CIMug gradients; the wordmark is `#231F20` with "Cim" in brand blue `#0058A9` (white and light teal `#7FD3DC` on dark backgrounds); the page badge is outlined in navy `#0A2E57` with `#8A96A3` text lines, and the glint is brand teal `#0097A5`.
